# Engenharia reversa — protótipo de marketplace

Protótipo educacional inspirado nas capturas de tela fornecidas. Não é um produto oficial e não se conecta aos sistemas do Mercado Livre.

## Como executar
1. Extraia a pasta `engenharia reversa` para a Área de Trabalho.
2. Abra `index.html` com o Google Chrome.
3. As imagens dos produtos são carregadas de URLs externas; conexão com a internet é necessária para vê-las.

## Funcionalidades demonstrativas
- Página inicial inspirada na captura original.
- Catálogo de 20 produtos fictícios, com imagens, preço e desconto.
- Busca, categorias e ordenação.
- Página exclusiva de Ofertas com filtros por ofertas relâmpago, preços baixos, outlet, celulares, notebooks e moda.
- Paginação de ofertas e navegação por letra inicial.
- Página de cadastro inspirada na referência enviada, com e-mail, nome e opção visual de Google.
- Carrinho com quantidades, remoção, subtotal, cupons e total.
- Favoritos salvos localmente no navegador.
- Cupons de demonstração: `PRIMEIRACOMPRA`, `CASA10` e `TECH20`.
- Detalhes de produto, formulários demonstrativos de login, cadastro de vendedor, contato e CEP.
- Configuração local de cookies e rodapé com ações.
- Layout responsivo para computador e celular.

## Limitações
Produtos, preços, descontos e contas são fictícios. Login, cadastro, Google, pedidos, estoque, frete, checkout e pagamentos não se conectam a serviços reais. Nenhuma compra real é realizada.
